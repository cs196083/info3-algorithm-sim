1. 표준 입출력 100~104쪽

표준 입출력 = 장치를 따로 지정하지 않으면 키보드로 입력하고 모니터로 출력하는 것

표준 출력 print()

  • 쉼표(,)로 여러 값을 출력하면 값 사이에 공백이 들어가요.
  • 다른 자료형을 함께 이어 출력하려면 str() 로 문자열 변환 후 + 로 연결.
  • f-문자열 포매팅 : print(f'{school}고등학교 {grade}학년') — 문자열 앞에 f, 값은 {변수명}
  • 여러 줄 출력: '''...'''(따옴표 3개) 또는 이스케이프 문자 \n(줄바꿈), \t(탭)

표준 입력 input()

변수 = input('입력을 위한 안내 문구')
input() 으로 받은 값은 항상 문자열(str)! 숫자로 계산하려면 int() 또는 float() 로 변환해야 해요.
예) '10' + '3.14' → '103.14' (문자열 연결) / int('10') + float('3.14') → 13.14 (정수+실수 → 실수)

2. 파일 입출력 105~108쪽

방대한 자료는 input() 으로 하나씩 입력하기 어렵고, 표준 입출력으로 처리한 결과는 프로그램이 끝나면 사라져요. → 표준화된 형태의 파일로 저장하고 필요할 때 불러와요.

① 파일 열기 open()→② 파일 처리(읽기/쓰기)→③ 파일 닫기 close()
함수기능사용 방법
open()파일 열기파일객체 = open('파일이름','모드')
close()파일 닫기파일객체.close()
write()파일에 내용 쓰기 (문자열 1개)파일객체.write("내용")
read()내용 전체 읽기변수 = 파일객체.read()
readline()내용 한 줄 읽기변수 = 파일객체.readline()
모드의미
'r'읽기(read)
'w'쓰기(write) — 파일이 없으면 새로 만들고, 있으면 기존 내용을 모두 삭제
'a'기존 내용 뒤에 추가(append)
csv 파일 : Comma Separated Value, 데이터를 쉼표(,)로 구분해 저장한 형식(엑셀로 열 수 있어요). 새 줄에 이어 쓰려면 쓰는 내용 끝에 \n.
with 키워드 : with open('hello.txt','a') as f: 블록을 벗어나면 close() 없이도 자동으로 닫혀요. (107~108쪽 알고 가기)

핵심 정리

  1. 표준 입출력 = 키보드 입력 + 모니터 출력
  2. 파일 입출력은 방대한 자료를 공유·분석하기 좋게 저장하고 불러오는 방법
  3. 절차: 파일 열기 → 파일 처리 → 파일 닫기
