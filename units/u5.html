2. 선택 구조 111~115쪽

구조형식설명
ifif 조건식:
  문장 1		조건이 참이면 문장 1 실행
if ~ elseif 조건식:
  문장 1
else:
  문장 2		참이면 문장 1, 거짓이면 문장 2
if ~ elif ~ elseif 조건식 1:
  문장 1
elif 조건식 2:
  문장 2
else:
  문장 3		위에서부터 차례로 검사, 모두 거짓이면 else. elif 는 필요한 만큼 추가
중첩 선택if 안에 또 다른 if여러 상황에 따라 실행 (양수·0·음수 구분)
들여쓰기가 실행 범위를 결정해요. 콜론(:) 다음 줄은 반드시 들여쓰기! else 는 없어도 돼요.

비교 연산자 > < >= <= == != , 논리 연산자 and / or / not 은 조건식에서 유용하게 쓰여요. (114쪽 알고 가기)

3. 반복 구조 116~119쪽

  • for 변수 in 리스트(또는 문자열): 첫 요소부터 마지막 요소까지 차례로 변수에 담아 반복
  • range(시작, 종료, 증감) : 시작 값부터 종료 값 직전까지 증감 값만큼 변화. 시작·증감은 생략 가능
    range(3)→0,1,2 · range(1,3)→1,2 · range(5,0,-2)→5,3,1
  • while 조건식: 조건이 참인 동안 반복, 거짓이면 종료 (반복 변수 갱신을 잊으면 무한 반복!)
  • 중첩 반복 : 반복 안의 반복. 이차원 리스트 탐색·출력에 유용. print(j, end=' ') 로 한 줄에 이어 출력
1~100의 합 : s = sum(range(1, 101, 1))

4. 데이터 구조 – 리스트 120~121쪽

데이터 구조 = 많은 데이터를 효율적으로 처리·관리하기 위한 구조 (주로 리스트). 변수 5개가 필요할 때 리스트 1개로 해결!
  • 1차원 리스트 s = ['김OO','남','1학년',85,90] → 인덱스는 0부터 시작: s[2] = '1학년'
  • 2차원 리스트 s = [[값,값,…],[값,값,…]] → s[행][열] / 값 출력은 중첩 반복문
  • 2차원 이상의 다차원 구조는 이미지·비디오 데이터, 기계학습 데이터, 여러 속성을 가진 데이터 저장에 활용돼요. (차원이 높아질수록 메모리·연산 속도에 유의)
