1. 파이썬의 자료형 91~94쪽

자료형에 따라 데이터를 처리·저장하는 방식이 달라져요. type() 함수로 자료형을 확인할 수 있어요.

자료형이름설명예시
수치형int소수점이 없는 정수1, 0, -1, 123
float소수점이 있는 실수3.14, -1.23, 5.0
문자열str작은/큰따옴표 1개 또는 3개로 감싼 문자 집합'Hello', "홍길동", '''123'''
불bool참/거짓. 예약어 True, False (첫 글자 대문자!)True, False
  • print('2+3') → 문자열이라 2+3 출력 / print(2+3) → 정수 연산 결과 5
  • 문자열 연산: + 는 문자열끼리 연결, * 는 문자열 × 정수로 반복. ('안녕'+'하세요', '파이썬'*3)
  • False로 취급되는 값: 숫자 0, 빈 문자열 '' / 그 외 숫자·문자열은 모두 True → bool() 로 확인

2. 변수 95쪽

변수 = 값을 저장하는 기억 장소 + 이름(변수명). 값은 바뀔 수 있고, 저장한 값에 따라 자료형이 자동 결정돼요. 대입 연산자는 =
변수명 규칙 ① 영문·한글·숫자·_ 사용 가능 ② 대소문자 구분 ③ 숫자로 시작 불가 ④ 예약어(if, for, while, and, or…) 불가 ⑤ 특수문자·공백 불가 ⑥ 여러 단어는 _ 로 연결(student_name)

기능덧셈뺄셈곱셈나눗셈몫나머지거듭제곱
비교>>=<<===!=

비교 연산의 결과는 불 자료형(True/False)!

논리기능
and모두 True일 때 True
or둘 중 하나만 True여도 True
notTrue면 False, False면 True
• 10/2 의 결과는 5.0 (나눗셈은 항상 float) • 배수 판별: 28 % 4 == 0 • 4와 7의 공배수: 28 % 4 == 0 and 28 % 7 == 0

핵심 정리

  1. 데이터를 올바르게 처리하려면 값의 종류에 맞는 자료형을 선택한다. (수치형·문자열·불)
  2. 변수 = 값을 저장하는 기억 공간. 값이 변할 수 있다.
  3. 산술·비교·논리 연산자로 문제를 해결한다.
