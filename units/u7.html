학습 목표

  • 정렬과 탐색의 개념을 이해하고, 실생활의 문제를 해결할 수 있다.
  • 다양한 정렬과 탐색 알고리즘의 특징과 효율을 비교·분석할 수 있다.

학습 요소: 정렬 알고리즘, 탐색 알고리즘

1. 정렬 알고리즘 133~137쪽

정렬 = 여러 데이터를 일정한 기준에 따라 순서대로 나열하는 것 (오름차순 / 내림차순). 데이터가 정렬되어 있으면 원하는 자료를 쉽고 빠르게 찾을 수 있어요.

선택 정렬

  1. 정렬되지 않은 데이터 중 첫 번째 위치의 데이터를 기준으로 정한다.
  2. 가장 작은 데이터를 찾아 기준 데이터와 위치를 바꾼다.
  3. 자리가 정해진 데이터를 뺀 나머지에 ①~③ 반복.

6개 공 : 5+4+3+2+1 = 15회 비교. 10개면 45회, 1,000개면 499,500회 → 작은 규모에 적합

퀵 정렬

  1. 첫 번째 데이터를 기준으로 정한다.
  2. 기준보다 작은 데이터는 왼쪽 그룹, 큰 데이터는 오른쪽 그룹으로 나눈다.
  3. 각 그룹의 데이터가 한 개가 될 때까지 ①~③ 반복.

6개 공 : 5+1+2 = 8회 비교. 가장 빠른 알고리즘 중 하나이나 기준 값 선택에 따라 효율이 달라져요.

퀵 정렬의 기준이 가장 작은/큰 값이면 그룹이 한쪽으로 치우쳐 비교가 많아지고, 중앙값이면 비교가 크게 줄어요. [7,1,2,6,3,5,4] → 첫 번째 기준 21회, 중앙 기준 12회. (내림차순은 가장 큰 값을 선택하는 식으로 바꿔요.)

그 밖의 정렬: 버블 정렬, 삽입 정렬, 합병 정렬 등

2. 탐색 알고리즘 138~141쪽

탐색 = 여러 데이터 중에서 원하는 것을 찾아내는 작업

순차 탐색

  1. 탐색하려는 데이터와 첫 번째 데이터를 비교
  2. 같으면 종료, 다르면 다음 데이터와 비교
  3. 마지막까지 비교해도 없으면 없다고 판단

정렬되지 않은 데이터에도 사용 가능. 데이터가 많으면 비교 횟수가 크게 늘어 데이터가 적을 때 효과적

이진 탐색

  1. 탐색 범위의 중간 데이터를 기준으로 정함
  2. 같으면 종료. 찾는 값이 더 작으면 왼쪽, 더 크면 오른쪽 범위로 좁힘
  3. 범위가 없어질 때까지 반복

반드시 정렬된 데이터에서만 가능. 범위가 절반씩 줄어 데이터가 많을 때 훨씬 효율적 (1,000개 → 최악 10번)

중간 위치는 (처음 위치 + 마지막 위치) // 2 로 구해요. 정렬되어 있지 않다면 먼저 정렬한 뒤 이진 탐색!

핵심 정리

  1. 정렬: 선택 정렬, 퀵 정렬 — 규모와 기준 값에 따라 효율이 달라진다.
  2. 탐색: 순차 탐색(적은 데이터), 이진 탐색(많은 데이터, 정렬 필수).
