학습 목표

  • 복잡한 문제를 해결 가능한 작은 단위의 문제로 분해할 수 있다.
  • 문제를 분석하고 분해한 결과를 바탕으로 모델링할 수 있다.

학습 요소: 문제 분해, 모델링

1. 문제 분해 83쪽

문제 분해 = 한 번에 해결하기 어려운 복잡한 문제를 작은 단위의 단순한 문제로 나누는 것
예) 가족 여행 계획 → 여행지 결정 + 교통수단 확인 + 숙소 예약 + 식당 검색
분해 방법설명퍼즐 예
방법 ❶ 기능·자료 기준유사한 기능이나 자료를 기준으로 나눈 뒤 기능별로 순차 처리하늘·나무·꽃 등 요소별로 맞추기
방법 ❷ 동일 구조동일한 형태의 작은 문제로 나누어 반복적으로 해결그림을 A, B 두 영역으로 나눠 맞추기
분해할 때 주의: ① 작은 문제 사이의 순서·포함 관계에 유의 ② 작은 문제를 모두 수행했을 때 전체 문제가 오류 없이 해결되었는지 확인

2. 약속 장소 문제의 분해 84쪽

세 학생의 이동 거리 총합이 최소가 되는 약속 장소 찾기 →

분해 방법 ➊ 학생별
  • 한국이의 모든 좌표 이동 거리
  • 친구1의 모든 좌표 이동 거리
  • 친구2의 모든 좌표 이동 거리
  • 세 학생 거리의 총합
분해 방법 ➋ 구조가 같은 문제
  • 가로 방향에서 이동 거리 합이 최소인 지점
  • 세로 방향에서 이동 거리 합이 최소인 지점
  • 두 지점이 만나는 위치 구하기
맨해튼 거리 : 두 점 A(x1,y1), B(x2,y2) 사이 거리 = |x2−x1| + |y2−y1| (바둑판 모양 도로에서 실제로 이동해야 하는 거리)

3. 모델링 85~87쪽

모델링 = 글, 그림, 그래프, 표 등으로 작은 문제 사이의 관계를 구조화하여 복잡한 문제를 이해하기 쉬운 형태로 나타내는 것
  • 모델은 복잡한 문제가 어떤 작은 문제로 구성되어 있는지, 어떤 관계가 있는지를 보여 줘요.
  • 정보의 구조화(분류·체계적 표현)도 모델링의 한 방법이에요.
  • 약속 장소 문제 : 표 기반 모델링(가로·세로 방향 거리와 총합 표) / 이미지 기반 모델링(그림으로 거리 표현) → 답: (ㄴ, D)

핵심 정리

  1. 문제 분해 = 복잡한 문제를 작은 단위의 단순한 문제로 나누기
  2. 유사 기능·자료 기준 순차 처리, 또는 동일 형태로 분해해 반복 해결
  3. 모델링 = 글·그림·그래프·표로 관계를 구조화

4. 쾨니히스베르크의 다리 건너기 89쪽

오일러(1735)는 복잡한 지형·길·다리를 점과 선으로 단순화(모델링)해서 문제를 풀었고, 이것이 그래프 구조의 원형이 되었어요.
