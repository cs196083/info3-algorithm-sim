1. 객체지향의 이해 125~126쪽

프로그램이 길고 복잡해질수록 해석이 어려워요. 같은 목적의 변수·함수를 묶어 객체로 만들고, 객체들이 상호작용하며 실행되도록 구성하는 것이 객체지향이에요.

용어뜻자동차 공장 비유
객체동일한 목적·기능을 가진 속성과 메서드를 하나로 묶은 것파란 승용차, 빨간 SUV …
속성객체가 가지고 있는 자료종류, 색, 생산 일자
메서드객체가 수행하는 기능 (클래스 안의 함수)반자율주행, 차선 유지, 자동 주차
클래스객체들이 갖는 속성과 메서드를 정의한 틀(설계도)자동차를 만들기 위한 설계
인스턴스클래스를 바탕으로 소프트웨어(메모리)에 구현된 구체적인 실체공장에서 실제로 만들어진 한 대
객체는 속성과 메서드를 반드시 둘 다 가질 필요는 없어요. 클래스 하나로 여러 객체를 만들 수 있고, 클래스를 고치면 객체를 한 번에 수정할 수 있어 효율적이에요. 반복되는 코드도 줄어요.

2. 클래스 만들기와 인스턴스 생성 127~129쪽

class Students:                       # 클래스 생성 (이름은 대문자로 시작하는 것이 일반적)
  def __init__(self, name, informatics, math):
    self.name = name                  # 속성
    self.informatics = informatics
    self.math = math
  def sum(self):                      # 메서드
    return self.informatics + self.math
  def avg(self):
    return self.sum() / 2
  def string(self):
    return '{}\t{}'.format(self.name, self.avg())

students = [Students('김OO', 88, 90), Students('정OO', 73, 65)]   # 인스턴스 생성
print(students[0].informatics)        # 속성 접근 → 88
print(students[0].avg())              # 메서드 호출
  • class 클래스이름: 으로 만들고, 인스턴스 = 클래스이름(값…) (생성자 함수)로 인스턴스를 만들어요.
  • __init__(self, …) : 인스턴스가 만들어질 때 속성 값을 저장하는 메서드. 클래스 함수의 첫 번째 매개변수는 관례적으로 self
  • self.식별자 로 자기 자신의 속성·기능에 접근. 처리 결과는 return 으로 반환
  • isinstance(인스턴스, 클래스) : 그 클래스로 만들어졌으면 True (알고 가기)

추상화상속캡슐화다형성
