학습 목표

  • 알고리즘이 무엇인지 알고 문제를 해결하기 위한 절차를 설명할 수 있다.
  • 추상화, 알고리즘 설계, 자동화를 통해 문제를 해결할 수 있다.

학습 요소: 문제, 문제 해결 절차, 추상화, 알고리즘, 자동화

1. 알고리즘이란? 77쪽

알고리즘 = 문제를 해결하기 위한 구체적인 방법과 절차

양치질 순서, 길 찾기, 게시글 정렬, 영상·상품 추천처럼 우리 일상에는 이미 많은 알고리즘이 쓰이고 있어요. (알고리즘이라는 말은 9세기 페르시아 수학자 알콰리즈미의 이름에서 유래했어요.)

2. 문제와 문제 해결 절차 78쪽

문제 = 목표로 하는 상태와 현재의 상태가 일치하지 않는 상황
문제 해결 = 초기 상태에서 시작해 목표 상태에 도달하는 과정 (둘의 차이를 줄여 나가는 것)

컴퓨터로 계산 문제를 해결하려면 3단계를 거쳐요.

단계하는 일예시(왕의 열쇠 문제)
① 추상화문제를 이해·분석해 핵심 요소를 뽑고, 풀기 쉬운 형태로 재표현
(초기/목표 상태, 핵심 요소, 수행 작업 정의 · 분해와 모델링)		총 관람객 수, 입장 순서, 범인만 거짓말한다는 사실 → “절반씩 나누는 횟수 세기”
② 알고리즘 설계순차·선택·반복 구조로 절차를 나열 (자연어·의사 코드·순서도)visitors ← visitors // 2, count ← count + 1 을 반복
③ 자동화프로그래밍 언어로 구현하고, 실행 결과를 분석하여 성능 평가파이썬 while문으로 구현 → 답 16명

3. 알고리즘의 5가지 조건 79쪽

입력출력명확성유한성수행 가능성
필요한 데이터를 입력받을 수 있어야 함적어도 1개 이상의 결과가 출력모호함 없이 의미가 분명반드시 종료되어야 함모든 명령이 수행 가능

알고리즘의 표현 방법

  • 자연어 : 우리가 쓰는 말로 설명
  • 의사 코드(Pseudo code) : 프로그래밍 언어와 비슷하지만 컴퓨터에서 실행되지 않는 가상의 코드
  • 순서도 : 약속한 도형과 흐름선으로 표현
  • 프로그래밍 언어 : 파이썬, C, C++ 등 (컴퓨터가 실행)
하나의 문제를 해결하는 알고리즘은 여러 개일 수 있어요. 비교·분석해서 더 좋은(효율적인) 알고리즘을 설계해야 해요.
