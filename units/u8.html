학습 목표

  • 문제 해결을 위한 프로그램을 협력적으로 설계하고 구현할 수 있다.
  • 문제 해결을 위한 프로그램의 성능을 평가하고 공유할 수 있다.

학습 요소: 프로그래밍 프로젝트, 성능 평가

1. 프로그래밍 프로젝트란? 145쪽

일정 관리, 가계부, 메신저, 영상 시청 프로그램처럼 프로그램은 우리 삶과 밀접해요. 배운 내용으로 실생활·여러 학문 분야의 문제를 해결하되, 여러 사람의 의견을 듣고 협력하면 더 효율적이에요. 프로젝트는 계획 → 구현 → 개선 과정을 포함해요.

단계하는 일
1. 주제 선정 및 문제 정의실생활·학문 분야 주제를 생각하고 브레인스토밍으로 탐색해 주제를 정한 뒤 해결할 문제를 구체적으로 정의. (우리와 관련 있는가? 많은 사람이 필요로 하는가? 프로그램으로 해결할 수 있는가?)
2. 추상화문제 분석(초기·목표 상태, 수행 작업) → 문제 분해(작은 문제) → 모델링(글·그림·그래프·표로 구조화)
3. 알고리즘 설계작은 문제별로 알고리즘을 설계 (자연어·순서도·의사 코드 중 편리한 방법)
4. 프로그램 작성설계한 알고리즘에 따라 프로그램 작성
5. 성능 평가 및 공유입력에 대해 의도대로 처리·출력하는지, 작은 문제를 모두 해결해 큰 문제를 효율적으로 해결했는지 확인 → 공유하고 피드백 반영해 최종 완성
모둠을 구성할 때 모둠장, 프로그래머, 발표자, 기획자 등 역할을 나누어 보세요.

2. 프로젝트 1 – 안전한 자율주행 자동차: 제동 거리 계산 146~148쪽

  • 초기 상태: 제동 거리 계산이 되지 않은 상태 → 목표 상태: 제동 거리를 계산한 상태
  • 작은 문제: ① 현재 속도(km/h)와 제동 가속도(m/s²) 입력받기 ② 제동 거리 계산하기 ③ 결과 출력하기
  • 단위 통일: v2 = v1 * 1000 / 3600 (km/h → m/s)
  • 제동 거리 = (현재 속도)² ÷ (2 × 제동 가속도의 크기) → 100 km/h, 15 m/s² 이면 약 25.7 m
  • 개선: 정지 거리 = 제동 거리 + 공주 거리 (공주 거리 = 현재 속도 × 공주 시간, 공주 시간 = 위험을 발견하고 제동이 걸리기 시작할 때까지의 시간)

3. 프로젝트 2 – 반려동물 등록 프로그램 149~152쪽

  • 작은 문제: 등록하기(명령 1) · 삭제하기(명령 2) · 목록 조회(명령 3) · 종료(명령 4)
  • 클래스 Register : 속성 등록 번호·동물 이름·동물 종류·등록자, 메서드 print_object()
  • 빈 리스트를 만들고, 무한 반복(while 1)으로 명령을 입력받아 선택 구조로 처리, 4번이면 break
  • enumerate() : 리스트의 인덱스와 원소에 동시에 접근하는 내장 함수
디버깅(Debugging) : 결과가 원하는 대로 나오지 않거나 오류가 날 때 코드를 처음부터 한 줄씩 확인하며 오류를 찾아 고치는 과정. (그레이스 호퍼가 컴퓨터 회로에 낀 나방(Bug)을 제거한 데서 유래) 145쪽

4. 온라인 저지 153쪽

프로그래밍 문제의 코드를 온라인으로 제출하면 서버에서 컴파일하고 제한 시간 안에 정확한 답을 내는지 실시간으로 채점해 주는 웹 기반 플랫폼. 컴퓨팅 사고력을 점검할 수 있어요. 대표적으로 코드업, 프로그래머스, 백준이 있어요.
